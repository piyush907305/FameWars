# Fame Wars v0.1.0 — Phase 1 release notes

**Fight for the spotlight.** Private combat prototype, placeholder art. This is not production launch clearance.

## Included

- Two original fictional fighters, Dynamo and Chalk; one Film City street arena; generic data-driven roster.
- Local two-player keyboard/two-gamepad input and player-vs-CPU with three difficulties; mobile landscape touch controls.
- 60 Hz deterministic integer sim, JSON snapshots, stored seed, explicit transition table, damage/hit detection, blockstun/hitstun, stamina/regeneration/stagger, dash and super meter.
- 45-second rounds, best-of-three, KO/timeout/sudden death, winner-only non-damaging flourish with camera/captions and original generated tone.
- React title/select/HUD/pause/results/settings, Hindi/English text, key remapping, reduced motion, volume, always-on subtitles and debug overlay.
- Pinned pnpm workspace/toolchain and action commits, Vitest/golden replay tests, Playwright acceptance suite, CI lint/typecheck/tests/build/browser workflow, guides and checkpoint history.

## Verified / not verified

See [the test report](21-v0.1.0-test-report.md) for actual counts, sizes and host-browser samples. A correct 0–2 CPU match result was observed through the real production UI. Local standalone Playwright browser launch is sandbox-blocked; its acceptance assertions have not been reported as passing. No claim that Redmi/iPhone/controller/4G/thermal/battery targets pass. Native Hindi copy/voice quality needs human review; placeholder sound is not speech.

## Excluded

Polished/AI-generated assets, real-person content, online multiplayer, sign-in/accounts/ranking, ads/rewards/purchases, native wrappers, live remote roster service, guaranteed offline PWA, rollback networking and global launch. Public licensing/privacy/age/gaming-rule/provider gates remain in force. No GitHub remote configured without owner/repo/visibility. Source-hosting repository is separate from GitHub.

## Recommended Phase 2 — requires owner approval

1. Playtest the current controls/stamina/finisher flow with adult testers; collect observations without trackers. Resolve feel/balance before art expansion.
2. One original character benchmark: AI-generated source if commercially cleared, cleaned shared rig, actual mobile deformation and size tests. Do not expand roster until it passes. Audit every asset/voice output; no celebrity references.
3. Physical Android/iPhone and two-gamepad QA, real 4G cold starts, 20-minute thermal/battery tests; lower visuals if budgets fail.
4. Bilingual copy and original Hindi/English synthetic voice trial with fluent reviewers, captions and licence evidence. No voice cloning.
5. Finish public-launch readiness gaps: chosen publisher/privacy contact, signed revocation manifest/service, privacy/age assurance review, content provenance and error recovery. Online/ad work stays separately gated.

No Phase 2 implementation, paid services or public production launch has started. Wait for owner's approval.
