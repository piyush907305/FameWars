## Playwright and CI — blocked, not passed

Three Playwright acceptance scenarios are implemented: real UI best-of-three completion through normal player input and virtual clock (no health/win cheat); pause/remap/language/reduced-motion/debug; mobile touch dimensions/portrait. On this host the installed Chrome process aborts at launch under workspace sandbox (SIGABRT / EPERM cleanup), **before page navigation**. Therefore none of those standalone Playwright assertions ran successfully here. Do not report them as gameplay failures or test passes.

The same product flows were exercised through the supported embedded-browser interface as described above. This supplements but does not replace the required Playwright run. CI is configured to install Chromium and run lint/typecheck/boundary/unit/build/E2E on every PR, with artifacts; GitHub is connected as piyush907305, but the supplied FameWars repository is public and public publication is approved; remote CI execution is pending, so no GitHub CI execution/pass is claimed. ## Known limitations / bugs / remaining gates

- Placeholder meshes/poses only; no skeletons or AI assets. CPU/balance/controls need real playtesting; first-to-two rules are proven, combat feel is not user-approved.
- No physical two-pad, multi-touch, keyboard rollover or audio-speaker listening test. Pad assignment logic has unit tests; browser bridge behavior still needs devices. Synth tone creation wired, audible output not human-listened here.
- Some production/technical labels and touch actions retain English abbreviations under Hindi; full native copy proofread pending. No lip-sync or spoken dialogue. Subtitles always visible.
- Local storage may fail in restricted browsers; app falls back to defaults. Settings remain local only. Desktop keyboard without numpad needs remap. Player 2 has no touch layout.
- Single background/portrait local pause, no multiplayer. Sudden-death repeated ties may replay a drawn round; no esports precision/ranking claim.
- Fighter kill-switch keys exist in data, but signed live revocation service/cache expiry enforcement is not implemented. It remains a public-launch gate from Phase 0. No global public production approval.
- No service worker/offline guarantee or native wrapper; PWA readiness is architecture only. Public privacy/age/gaming/legal/operator details remain unresolved.
- No accounts/online/ads/telemetry; hosting may still have operational logs and private preview access control. Game self-declared age gate is not verified identity/child-compliance proof.
- Main source licence not chosen; original content and third-party software rights separate. GitHub owner piyush907305 provided; private fame-wars name inferred (A34). Connection verified as piyush907305; connector cannot create repositories and browser is separately signed out. FameWars access verified; public source publication approved; no remote push/CI pass claimed.
- ESLint 9 compatibility line is pinned and installed successfully but provider marks it out of support; Vite 6/Vitest 3 chosen compatibility lines also need a dependency/support review before public launch. This prototype is not a security audit.
